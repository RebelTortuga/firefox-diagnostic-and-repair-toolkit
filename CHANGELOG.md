# Changelog
## Version 1.0.0
- Graphical interface with section navigation, action buttons and a results area.
- Automatic detection of registered and standard Firefox profiles, with custom browsing and remembered selection.
- Diagnostics Center with quick/full local scans and optional TXT or Markdown report export.
- Category-selectable backup for bookmarks, passwords, extensions and supporting data, and browser preferences.
- SHA-256 backup verification and recovery-profile protection during restore.
- Troubleshoot Mode, startup-cache recovery action, guided Refresh Firefox, Profile Manager and about:support.
- Hidden-console launcher and hidden backup/verification processes.
- Firefox closure reminder at the top, results caption above the box, guide below Other Tools, and Optional Support evenly positioned between the guide and Exit.
- Initial optional-support control, subsequently connected to the confirmed Ko-fi page.
- GitHub documentation, feedback instructions and ignore rules. Headings directly precede their descriptions without blank lines or HTML breaks.

## Limitations

Backups exclude session tabs, history, cookies and website data. Encryption, independent restore-category selection and full-profile backup are not implemented.

## Button order and colors
The left-side buttons appear in this order:
1. **Profile and Folders**
2. **Backup & Restore**
3. **Diagnostics** — green
4. **Repair & Troubleshoot**
5. **Other Tools**
6. **Detailed Options Guide (H)** — yellow
7. **Optional Support** — blue
8. **Exit Toolkit** — red with white text

The guide is directly below Other Tools. Optional Support remains evenly positioned between the guide and Exit. These button colors remain in place when switching sections. The toolkit starts on Profile and Folders. Version remains **1.0.0**.
